# SpecFlowLab 1.0.9

SpecFlowLab 1.0.9 makes opening projects and preparing focused evidence more
direct.

## Highlights

- Double-click a `.sflproj` on macOS or Windows to launch SpecFlowLab and load
  that project. If the running workspace has unsaved changes, SpecFlowLab keeps
  it intact and asks you to save before replacing it.
- Import spectra, characterization files, figures, manuscripts, and literature
  through one evidence panel. The relation-map workflow is no longer shown.
- AI Investigation now offers Selected datasets, Current folder, and Entire
  project. These are quick presets; every dataset can still be selected or
  deselected in the list.
- Local paths and operator or computer names are removed automatically from AI
  evidence. Raw sources and full treated matrices remain explicit Full-evidence
  options.
- Reset to 3 Components restores the default automatic fitting inputs without
  erasing the last fit result.
- Dataset comparisons default to solid Origin-classic colors, and the overall
  application palette is calmer and more consistent.

## Distribution note

The macOS build is ad-hoc signed and not notarized. Windows installers and the
portable executable are produced by GitHub Actions. Windows packaging is
validated in CI; physical Windows and OriginPro runtime behavior still requires
testing on the intended workstation.
