# Security policy

Please do not report security vulnerabilities in a public issue.

Send a concise report, reproduction steps, affected version, and safe contact
details to specflowlab@icluod.com. Do not attach private spectra, patient
data, credentials, or proprietary project files.

SpecFlowLab is a public beta. Until a security process is formalized, users
should keep sensitive source data in project folders that are not shared with
the application or repository.
